# Examples

This folder is the public example layer for the validated path.

Main areas:

- `targets/`
  named target bundles
- `profiles/`
  named OCR profiles
- `scenarios/`
  repository-level multi-object scenarios
- `logs/`
  representative evidence logs and readback files

Single-action example configs:

- `append_text.notepad.json`
- `prepend_text.notepad.json`
- `replace_text.notepad.json`
- `write_if_missing.notepad.json`
- `append_timestamped_note.notepad.json`

For the generated evidence index, see:

- `docs/evidence-index.md`

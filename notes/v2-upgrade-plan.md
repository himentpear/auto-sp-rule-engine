# 0.2.0 Upgrade Plan

Date: 2026-03-19

## Mission

Turn the repository into a cleaner, more coherent, more polished 0.2.0 release candidate without widening the validated execution boundary.

## Work Packages

1. repository structure and release-quality consolidation
2. frontend 0.2.0 read-only polish
3. evidence and examples consolidation
4. developer-experience and repo-tooling cleanup
5. final validation and release-readiness summary

## Non-goals

- mouse automation
- low-level keyboard simulation as a primary path
- frontend execution controls
- frontend config editing
- frontend file write-back
- LLM-driven execution

## Expected Outcome

A release-candidate repository state that is easier to open tomorrow, easier to validate safely, more polished in the read-only frontend, and more explicit about scope.
